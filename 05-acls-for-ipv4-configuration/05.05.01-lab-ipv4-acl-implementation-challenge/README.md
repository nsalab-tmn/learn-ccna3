## Описание сценария

Список контроля доступа (ACL) — последовательность записей permit и deny, по которой маршрутизатор решает, пропустить пакет или отбросить его. Стандартный список проверяет только адрес источника пакета, а расширенный — также адрес назначения, протокол и порт TCP или UDP; список обозначается номером или именем. Список применяют к входящему или исходящему трафику интерфейса, а к линиям VTY — чтобы ограничить, с каких адресов можно подключиться к самому маршрутизатору. Пакет, не совпавший ни с одной записью, отбрасывается: в конце каждого списка действует неявная запись deny any.

Согласно сценарию, компания соединила сеть головного офиса HQ с сетью филиала Branch и подключила головной офис к Интернету через провайдера ISP. Служба безопасности задала требования к связи: из Интернета нельзя подключаться по FTP к корпоративному веб-серверу и отправлять эхо-запросы узлам первой локальной сети головного офиса, узлы этой сети не должны получать доступ к серверу филиала, а узлы филиала — к ней самой, и управлять маршрутизатором HQ по сети можно только из второй локальной сети головного офиса, где работает компьютер администратора. Вам, сетевому администратору компании, нужно настроить на маршрутизаторах HQ и Branch четыре списка контроля доступа, применить их там, где указывают требования, и проверить, какой трафик они пропускают. Это лабораторная работа на проверку навыков: в ней перечислены требования к результату, а команды для их выполнения вы выбираете сами.

## Задачи лабораторной работы

- Настроить на маршрутизаторе HQ расширенный нумерованный список контроля доступа 101 для трафика из Интернета
- Настроить на маршрутизаторе HQ расширенный нумерованный список контроля доступа 111 для трафика локальной сети HQ LAN 1
- Ограничить доступ к линиям VTY маршрутизатора HQ стандартным именованным списком контроля доступа vty_block
- Настроить на маршрутизаторе Branch расширенный именованный список контроля доступа branch_to_hq
- Проверить, какой трафик пропускают списки контроля доступа

## Описание топологии

Топология состоит из маршрутизаторов HQ, Branch и ISP, коммутаторов HQ-S1, HQ-S2, BR-S3, BR-S4, ISP-S1 и ISP-S2, компьютеров PC-1, PC-2, PC-3, Admin, Branch-PC и Internet-User и серверов Enterprise-Web-Server, Branch-Server и External-Web-Server: маршрутизатор HQ соединен последовательными каналами с маршрутизатором Branch и с маршрутизатором ISP, который представляет Интернет, а компьютеры и серверы подключены к локальным сетям маршрутизаторов через коммутаторы.
