## Описание сценария

Список контроля доступа (ACL) — последовательность записей permit и deny, по которой маршрутизатор решает, пропустить пакет через интерфейс или отбросить его. Стандартный список проверяет только адрес источника пакета, а расширенный — также адрес назначения, протокол и порт TCP или UDP, поэтому расширенным списком можно разрешить узлу одну службу сервера и запретить остальные. Пакет, не совпавший ни с одной записью, отбрасывается: в конце каждого списка действует неявная запись deny any.

Согласно сценарию, сеть предприятия состоит из трех сегментов, соединенных маршрутизатором R1: в одном работает компьютер PC1, во втором — компьютер PC2, в третьем установлен сервер Server. Сотруднику за компьютером PC1 нужен доступ к серверу только по протоколу FTP, а сотруднику за компьютером PC2 — только к веб-сайту сервера по протоколу HTTP. Оба компьютера должны получать ответы на эхо-запросы от сервера, но не друг от друга. Вам, сетевому администратору предприятия, нужно настроить на маршрутизаторе R1 расширенный нумерованный список контроля доступа для сети компьютера PC1 и расширенный именованный список для сети компьютера PC2, применить их к интерфейсам маршрутизатора и проверить, какой трафик они пропускают.

## Задачи лабораторной работы

- Проверить связь компьютеров PC1 и PC2 с сервером и друг с другом до настройки списков контроля доступа
- Настроить расширенный нумерованный список контроля доступа 100 для сети компьютера PC1
- Применить список 100 к интерфейсу G0/0 маршрутизатора R1 и проверить его работу
- Настроить расширенный именованный список контроля доступа HTTP_ONLY для сети компьютера PC2
- Применить список HTTP_ONLY к интерфейсу G0/1 маршрутизатора R1
- Проверить, какой трафик пропускают списки контроля доступа

## Описание топологии

Топология состоит из маршрутизатора R1, трех коммутаторов S1, S2, S3, компьютеров PC1, PC2 и сервера Server: к каждому из интерфейсов G0/0, G0/1 и G0/2 маршрутизатора подключен свой коммутатор, а к коммутаторам S1, S2 и S3 — компьютер PC1, компьютер PC2 и сервер соответственно.
