## Описание сценария

Маршрут по умолчанию (0.0.0.0/0) указывает маршрутизатору, куда отправлять пакеты для сетей, которых нет в его таблице маршрутизации, — как правило, к интернет-провайдеру. Его настраивают статически на пограничном маршрутизаторе, подключенном к провайдеру, а остальным маршрутизаторам сети его может передать протокол OSPF: по команде default-information originate пограничный маршрутизатор объявляет маршрут по умолчанию своим соседям OSPF. Так маршрут по умолчанию не приходится настраивать вручную на каждом маршрутизаторе.

Согласно сценарию, сеть организации из трех офисов построена на маршрутизаторах R1, R2 и R3, которые обмениваются маршрутами по протоколу OSPF. Маршрутизатор R2 подключен к интернет-провайдеру — маршрутизатору ISP, за которым находится веб-сервер Web-Server, но компьютеры офисов пока не могут к нему обратиться: маршрута в Интернет нет ни на одном маршрутизаторе организации. Вам, сетевому администратору организации, нужно настроить на маршрутизаторе R2 маршрут по умолчанию к провайдеру, распространить его по протоколу OSPF на маршрутизаторы R1 и R3 и проверить, что компьютеры всех офисов получают доступ к веб-серверу.

## Задачи лабораторной работы

- Проверить связь компьютеров с веб-сервером и таблицы маршрутизации до настройки
- Настроить статический маршрут по умолчанию на маршрутизаторе R2
- Распространить маршрут по умолчанию по протоколу OSPF
- Проверить связь компьютеров всех офисов с веб-сервером

## Описание топологии

Топология состоит из маршрутизаторов R1, R2 и R3 сети организации, коммутаторов S1, S2 и S3, компьютеров PC1, PC2 и PC3, маршрутизатора провайдера ISP и веб-сервера Web-Server: маршрутизаторы R1, R2 и R3 соединены последовательными каналами, к каждому из них через свой коммутатор подключен один компьютер, а маршрутизатор R2 соединен последовательным каналом с маршрутизатором ISP, к которому подключен веб-сервер.
