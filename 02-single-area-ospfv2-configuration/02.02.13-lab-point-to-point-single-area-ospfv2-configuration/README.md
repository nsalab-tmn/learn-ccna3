## Описание сценария

OSPF (Open Shortest Path First) — протокол динамической маршрутизации по состоянию каналов: маршрутизаторы находят соседей пакетами приветствия, устанавливают с ними смежность, обмениваются сведениями о своих каналах и сами вычисляют кратчайшие пути ко всем сетям. Каждый маршрутизатор OSPF отличается идентификатором маршрутизатора — 32-битным числом в виде IPv4-адреса. Интерфейсы включают в OSPF командами network с шаблонной маской в режиме настройки процесса или командой ip ospf на самом интерфейсе. На интерфейсах в сторону локальных сетей, где нет других маршрутизаторов, пакеты приветствия не нужны, и такие интерфейсы делают пассивными.

Согласно сценарию, три офиса компании соединены последовательными каналами «точка-точка»: маршрутизаторы R1, R2 и R3 образуют треугольник, и за каждым из них находится локальная сеть офиса. Адреса интерфейсов уже назначены, но маршрутизаторы знают только свои подключенные сети, и компьютеры разных офисов не могут обмениваться данными. Вам, сетевому администратору компании, нужно настроить на маршрутизаторах протокол OSPF в одной области: задать идентификаторы маршрутизаторов, включить OSPF тремя разными способами — командами network с шаблонной маской на R1, командами network с адресами интерфейсов на R2 и командами на интерфейсах R3, — сделать интерфейсы локальных сетей пассивными и проверить, что маршруты распространились.

## Задачи лабораторной работы

- Задать идентификаторы маршрутизаторов OSPF на R1, R2 и R3
- Включить OSPF на маршрутизаторе R1 командами network с шаблонной маской
- Включить OSPF на маршрутизаторе R2 командами network с адресами интерфейсов
- Включить OSPF на интерфейсах маршрутизатора R3
- Сделать пассивными интерфейсы локальных сетей
- Проверить соседей, маршруты OSPF и связь между офисами

## Описание топологии

Топология состоит из трех маршрутизаторов R1, R2, R3, трех коммутаторов S1, S2, S3 и трех компьютеров PC1, PC2, PC3: маршрутизаторы попарно соединены последовательными кабелями, а к каждому маршрутизатору через свой коммутатор подключен один компьютер.
