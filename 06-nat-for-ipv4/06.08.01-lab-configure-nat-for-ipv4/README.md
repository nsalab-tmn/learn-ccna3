## Описание сценария

Преобразование сетевых адресов (NAT) позволяет узлам с частными IPv4-адресами обмениваться данными с узлами внешних сетей. Маршрутизатор NAT на границе сети заменяет в проходящем пакете частный адрес публичным и запоминает это соответствие в таблице преобразований, чтобы вернуть ответ отправителю. NAT с перегрузкой (PAT) позволяет многим узлам использовать один публичный адрес, различая их сеансы по номерам портов, а статический NAT постоянно связывает частный адрес сервера с публичным, поэтому сервер доступен извне. Какие адреса преобразовывать, маршрутизатор определяет по списку контроля доступа (ACL), а направление преобразования — по тому, какие его интерфейсы назначены внутренними (inside), а какие — внешними (outside).

Согласно сценарию, у компании три локальные сети с частными адресами — за маршрутизаторами R1, R2 и R3. Маршрутизатор R2 подключен к провайдеру, который выделил компании блок публичных адресов 209.165.202.128/30. Сотрудникам всех трех сетей нужен доступ в Интернет, а сервер local-pka в сети маршрутизатора R2 должен быть доступен из Интернета. Вам, сетевому администратору компании, нужно настроить NAT на маршрутизаторе R2: адреса всех трех локальных сетей преобразовывать в один публичный адрес с помощью NAT с перегрузкой, а адрес сервера local-pka — в другой публичный адрес с помощью статического NAT. Это лабораторная работа на проверку навыков: в ней перечислены требования к результату, а команды для их выполнения вы выбираете сами.

## Задачи лабораторной работы

- Настроить список контроля доступа с адресами, которые преобразует NAT
- Настроить NAT с перегрузкой (PAT) для трех локальных сетей
- Настроить статический NAT для сервера local-pka
- Назначить внутренние и внешний интерфейсы NAT
- Проверить доступ узлов компании в Интернет и доступ к серверу local-pka из Интернета

## Описание топологии

Топология состоит из маршрутизаторов R1, R2 и R3 с коммутаторами S1, S2 и S3, компьютеров PC1 и PC2 и сервера local-pka в сети компании, а также маршрутизатора провайдера Internet с коммутаторами ISP-SW1 и ISP-SW2, компьютера Outside-PC и сервера cisco-pka в Интернете.
