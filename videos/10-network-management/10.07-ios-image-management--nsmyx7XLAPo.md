## Цель для обучающегося

После просмотра обучающийся должен уметь обновить образ IOS на маршрутизаторе: подготовить TFTP-сервер на ПК (каталог с `.bin`, привязка к нужному сетевому интерфейсу, брандмауэр), проверить связность `ping`, посмотреть текущий образ и свободное место `show flash`, скопировать новый образ `copy tftp flash`, указать его командой `boot system flash:<имя>`, сохранить конфигурацию, перезагрузить и подтвердить `show version`.

Текст темы (10.7.2–10.7.5) уже описывает оба направления копирования (`copy flash: tftp:` — резервная копия, `copy tftp: flash:` — установка, в т.ч. по IPv6), команду `boot system` и проверку `show version` на примере ISR 4200 / IOS XE 16.9.4. Видео добавляет то, чего в тексте нет: **сторону ПК** — как выглядит и настраивается TFTP-сервер (Tftpd64: Base Directory, Bind TFTP to this address, ненужная, но требуемая программой вкладка DHCP), зачем выключать/настраивать брандмауэр Windows, консольное подключение PuTTY по serial, а также реальный, а не сокращённый вывод IOS 15.x на Cisco 1941 (две записи в `show flash` после копирования, сообщения загрузки после `reload`).

## Предложение по пересборке

**Формат:** видео с генерированным голосом (код-рендер терминала + две стилизованные панели «ПК»), ~3:30. Сессию также использовать как обучающий сценарий симулятора.

**Что переделать относительно оригинала:**
- Привести пример к той же платформе, что и текст темы (ISR 4200 / IOS XE 16.9.4 — `isr4200-universalk9_ias.16.09.04.SPA.bin`), либо, наоборот, оставить Cisco 1941 / IOS 15.x, но тогда согласовать имена в тексте. Ниже — вариант на 1941, как в видео (он честнее показывает классический IOS, с которым работает симулятор).
- Добавить пропущенный в видео шаг проверки свободного места во флеше (у текста это «Шаг 2») и подсказку сделать резервную копию старого образа (`copy flash: tftp:` — 10.7.3).
- Вместо «выключите брандмауэр Windows» — «разрешите входящий UDP/69 для tftpd64 или временно отключите брандмауэр».
- Вкладку DHCP у Tftpd64 опустить (особенность программы, не IOS), упомянуть одной фразой.

**Сцены для генератора (сцена → визуал → озвучка):**
1. Титул → карточка «Что нужно»: ПК (PuTTY + TFTP-сервер), консольный и Ethernet-кабель, маршрутизатор, файл `.bin`; мини-топология R1 (192.168.0.1, G0/0) — PC (192.168.0.10) → «Чтобы обновить IOS, нужны …».
2. Панель «TFTP-сервер на ПК» (стилизованная форма, не скриншот): Base directory `…\tftp-folder` с файлом `c1900-universalk9-mz.SPA.157-3.M5.bin`, Bind address `192.168.0.10`, замечание о брандмауэре → «Сервер отдаёт файлы из каталога …, слушает на адресе интерфейса, подключённого к маршрутизатору».
3. Терминал: `ping 192.168.0.10` → «Проверяем связность».
4. Терминал: `show flash` — одна запись, свободно 181 МБ; подсветить длину нового файла 85 МБ → «Места хватает».
5. Терминал: `copy tftp flash` с диалогом и строкой `!!!!`, `[OK - 85064020 bytes]` → «Копируем образ с TFTP-сервера».
6. Терминал: `show flash` — две записи → «Во флеше теперь два образа».
7. Терминал: `boot system flash:…`, `copy running-config startup-config` → «Указываем, с какого образа грузиться, и сохраняем».
8. Терминал: `reload`, сокращённый лог, `show version` с подсвеченной строкой `System image file is …157-3.M5.bin` → «Проверяем версию».

**Активы для отрисовки:** иконки маршрутизатора 1941/ISR и ПК; карточка-схема TFTP-сервера (каталог, интерфейс, порт UDP 69); рамка терминала.
