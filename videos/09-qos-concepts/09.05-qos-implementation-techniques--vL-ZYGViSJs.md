## Цель для обучающегося

Освоить практический «конвейер» QoS и инструменты маркировки. Понять три категории инструментов (классификация и маркировка; предотвращение заторов; управление заторами) и их **последовательность** на роутере: вход → классификация+маркировка → предотвращение заторов (полисинг/выборочный сброс) → управление заторами (очереди, планирование, шейпинг) → выход. Знать, где и чем маркируется трафик: L2 — CoS (802.1Q/802.1p, 3 бита), Wi-Fi TID, MPLS EXP; L3 — IP Precedence (3 бита) и DSCP (6 бит, до 64 классов, сквозная маркировка). Понимать поле ToS/Traffic Class: старое IPP (3 бита) → новое DSCP (6 бит) + ECN (2 бита); совместимость через Class Selector (первые 3 бита DSCP = CoS/IPP). Понимать границы доверия (trust boundary — маркировать как можно ближе к источнику, доверять IP-телефонам/AP/шлюзам), WRED (проактивный сброс TCP между мин. и макс. порогами) и разницу полисинга (сброс/перемаркировка лишнего → «пилообразный» выход) и шейпинга (буферизация и сглаживание → ровный выход).

Текст темы (9.5.2–9.5.13) покрывает всё это детально, включая значения CoS, таблицу DSCP (BE/EF/AF), формулу AFxy, совместимость CS и рекомендации по политике. Видео — визуальный проход по тем же слайдам. Самая ценная для нас часть — «последовательность QoS» и поля маркировки (питают lab по MQC/DSCP). CLI в ролике нет.

**Для симулятора (семя тренинга):** ролик без CLI, но это самая «практикопригодная» тема модуля 09. Пример учебной сессии маркировки/политики (для lab):

```text
R1(config)# class-map match-all VOICE
R1(config-cmap)#  match protocol rtp audio
R1(config-cmap)# exit
R1(config)# policy-map MARK-EDGE
R1(config-pmap)#  class VOICE
R1(config-pmap-c)#   set dscp ef                 ! голос -> DSCP EF (46)
R1(config-pmap-c)#  class class-default
R1(config-pmap-c)#   set dscp default            ! остальное -> BE (0)
R1(config-pmap-c)# exit
R1(config)# interface GigabitEthernet0/0
R1(config-if)#  service-policy input MARK-EDGE   ! маркировка ближе к источнику
R1(config-if)# exit
! шейпинг на выходе в WAN:
R1(config)# policy-map WAN-SHAPE
R1(config-pmap)#  class class-default
R1(config-pmap-c)#   shape average 2000000       ! сгладить до 2 Мбит/с
R1(config-pmap-c)# exit
R1(config)# interface Serial0/0/0
R1(config-if)#  service-policy output WAN-SHAPE
R1(config-if)# end
R1# show policy-map interface GigabitEthernet0/0
```
